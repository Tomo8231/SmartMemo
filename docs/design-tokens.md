# デザイントークン

`src/index.css` の `.app` で定義し、`.app.dark` で**同じ名前を差し替える**。
ダークで見た目が壊れるほとんどの原因は、個々のルールに `#hex` を直書きして
ダーク側の上書きを書き忘れることなので、色は必ずここを経由させる。

ベースカラー（5 色）と文字サイズ（小/中/大）は `src/App.tsx` の `appStyle` が
`--accent` / `--fs-*` をインラインで注入して上書きする。したがって
**アクセント色を直書きすると、その箇所だけベースカラー設定に追従しなくなる。**

| `--accent-text` | `#fff`※ | 同左 | `--accent` の上に載る文字 |
| `--coin` | `#f2c230` | 同左 | コインのみ。**ベースカラーに追従させない** |
| `--bg` | `#fafaf9` | `#141416` | アプリの地 |
| `--surface` | `#ffffff` | `#1e1e21` | カード・シート・ナビ |

※ ベースカラー設定で 5 色（オレンジ／インディゴ／グリーン／ローズ／スレート）に切り替わる。
既定値は `COLOR_PRESETS[0]`（オレンジ）。

**警告色をブランド色と兼ねない。** `--danger` を `--accent` で代用すると、
ベースカラーをローズにしたときに「目立つ＝異常」の対応が崩れる。

## 高さ

部品の縦寸法はここで 1 回だけ決める。個々のルールに px を書くと、
画面ごとにボタンの高さが数 px ずつずれていく。

| トークン | 値 | 用途 |
|---|---|---|
| `--h-header` | 52px | ヘッダー／フルスクリーンの戻るヘッダー |
| `--h-nav` | 76px | ボトムナビ |
| `--h-row` | 56px | タスク行・抽出結果行 |
| `--h-btn` | 44px | 通常のボタン・入力欄 |
| `--h-btn-lg` | 52px | 画面の主 CTA |
| `--h-chip` | 30px | フィルタ／選択チップ |
| `--h-fab` | 52px | 中央の FAB |
| `--tap-min` | 44px | タップ判定の最小サイズ |

## 文字サイズ・余白・影

`--fs-base` / `--fs-sm` / `--fs-xs` / `--fs-lg` は設定の文字サイズで上書きされる。
余白は 4px グリッドの `--sp-1`〜`--sp-5`、影は `--sh-1`〜`--sh-3` の 3 段階。

`--sh-*` は**影の値そのもの**（`0 2px 10px rgba(...)`）であって色ではない。
`box-shadow:0 4px 14px var(--sh-2)` のような書き方は無効になる。

## 例外（意図的に直書きが残っている箇所）

- **ガチャの演出**（`.gacha-beam-*`、`.gacha-rarity-flash`、レアリティのグラデーション）
  レアリティごとの色（rare=青／super=紫／ultra=金）は演出であり、
  同時に「どれだけ珍しいか」を示す情報でもあるため、ベースカラーに追従させない。
- **メモモンのドット絵パレット**と**餌・アイテムの絵文字**
  キャラクターのアートそのものなので UI トークンの対象外。
- **庭の空・草地**（`.gw-*` の風景描画）
  時間帯で変わる絵であり、ベースカラーとは別系統。
