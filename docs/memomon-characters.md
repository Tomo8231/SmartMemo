## 1. 共通の仕組み

### 1.1 性格（`personality`）

各個体は `active`（活発）か `lazy`（のんびり）のどちらかを**ランダムに1つ**持ちます（`MemoMonInstance.activity`）。
にわを歩き回る動きだけに影響し、セリフの内容は変わりません。

| パラメータ | active（活発） | lazy（のんびり） |
|---|---|---|
| 移動速度 | 45 | 18 |
| 上下のブレ幅 | 18 | 8 |
| 立ち止まる確率 | 45% | 75% |
| 歩く時間 | 1500〜3500ms | 600〜1600ms |
| 止まる時間 | 1500〜3500ms | 3000〜8000ms |

つまり **active はよく動き回り、lazy はほとんど座っている** という違いになります。

### 1.2 なつき度レベル

| なつき度 | 呼び名 | 星 |
|---|---|---|
| 90〜100 | 心の友 | ★★★★★ |
| 70〜89 | なかよし | ★★★★ |
| 40〜69 | 打ち解けた | ★★★ |
| 15〜39 | 挨拶仲間 | ★★ |
| 0〜14 | おはつ | ★ |

なつき度は**時間経過では減りません**（にわに出していない間も維持されます）。

### 1.3 セリフが出る場面

| 場面 | 使うセリフ | 出どころ |
|---|---|---|
| にわでタップ | 雑談 70% / 豆知識 30% | `MEMOMON_LINES[id].chat` / `.tip` |
| なでる | なでた反応 | `MEMOMON_REACTIONS[id].pet` |
| 好物をあげる | 大好物の反応 | `.feedFav` |
| ふつうの餌をあげる | ふつうの反応 | `.feedNormal` |
| 嫌いな餌をあげる | 嫌がる反応 | `.feedDis` |
| タスク完了 | 汎用の喜び | `CHEER_LINES_TASK` |
| おねだり | 要求ラベル | `MON_REQUEST_INFO` |

### 1.4 タスク完了時の汎用セリフ

メモモン別の台詞が用意されていない場面（タスク完了など）で使う共通プールです。

「やったね！」　「すごい！」　「えらい！」　「がんばったね」　「その調子！」　「おつかれさま！」

### 1.5 おねだり

にわのメモモンは、前回応えてから **20 分**経つとおねだりをします。応えると **なつき度 +3 / コイン +5**。
満腹度が 40 未満のときは 70% の確率で「ごはん」が選ばれます。

| 種類 | 表示 | 応えたとき |
|---|---|---|
| `food` | 🍚 おなかすいた！ | ごはんをあげた |
| `toilet` | 🚽 トイレ…！ | トイレをきれいにした |
| `play` | 🎾 あそんで！ | いっしょに遊んだ |

- **ごはん** … 餌えらびが開き、選んだ餌の好き嫌いに応じた反応セリフが出ます（満腹度 +25）
- **トイレ / あそび** … タップ一回で応え、`pet` の反応セリフが出ます

### 1.6 餌と好みの判定

| 餌 | グレード | コスト |
|---|---|---|
| 🍞 パン | ★ | 30 |
| 🌿 ハーブ | ★ | 30 |
| 🍎 りんご | ★★ | 80 |
| 🍪 クッキー | ★★ | 80 |
| 🍣 寿司 | ★★★ | 200 |
| 🍰 ケーキ | ★★★ | 200 |
| 🍖 ステーキ | ★★★★ | 500 |
| 🌟 メモモンフード | ★★★★ | 500 |

好みによって、なつき度と満腹度の増減が変わります（`computeFeedingEffect`）。

| 判定 | なつき度 | 満腹度 |
|---|---|---|
| 好物 | +10 + グレード×3 | +30 + グレード×10 |
| ふつう | +2 + グレード | +20 + グレード×8 |
| 嫌い | **-3** | +10 |

なつき度が MAX のときに「なでる」「好物をあげる」と、確率でおくりもの（各メモモン固有アイテム）や背景・サウンドが手に入ります。

### 1.7 進化

進化系は **なつき度 MAX の子をにわに出したままタスクを完了**すると進化に近づきます。
1→2 段階目に **20 タスク**、2→3 段階目に **50 タスク**。

ガチャに出るのは **1 段階目だけ**で、2・3 段階目は進化でしか出会えません。段階が上がるとレア度も上がります（レア → スーパー → ウルトラ）。

進化系はまだ 1・2 段階目のとき、豆知識に次の一文が加わります。

> 「なつき度MAXで、にわに出したままタスクを完了すると進化に近づくよ」
