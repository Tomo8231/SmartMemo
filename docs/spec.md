## 1. 概要

**SmartMemo** は、テキスト・音声・画像を入力して AI が TODO とアイデアに自動分類するメモアプリ。メモモン（ペットキャラクター）が画面を歩き回り、TODO 完了でコインを獲得してガチャを引く gamification 要素を持つ PWA。

- アプリ名: SmartMemo
- バージョン: 1.1.0 (TypeScript)
- 対応: PWA（オフライン対応）

## 5. メモ入力・解析システム

### 入力方法

| ボタン | 機能 |
|--------|------|
| マイクボタン | Speech Recognition API で音声認識。非対応時は Gemini Audio にフォールバック |
| カメラボタン | 画像アップロード → Gemini Vision / Claude Vision で OCR |
| AI 解析ボタン | テキストを解析して TODO・アイデアに振り分け |

### AI 解析の優先順位

1. **Gemini API**（apiKey 設定済みの場合）
2. **Claude API**（`window.claude.complete` が利用可能な場合）
3. **ローカルヒューリスティック**（`localParseAll`）

### ローカル解析ルール

**TODO 判定条件（いずれかを含む行）:**
- 行動動詞: 買う・やる・完了・提出・送る・確認・チェック・購入・予約・申請 など
- 日付トークン: 明日・来週・今日・月日表記・YYYY-MM-DD など

**日付パース対応形式:**

| 入力例 | 解析結果 |
|--------|----------|
| `明日` | startDate=翌日, endDate="" |
| `7月1日` | startDate=yyyy-07-01, endDate="" |
| `7月1日〜15日` | startDate=yyyy-07-01, endDate=yyyy-07-15 |
| `8月中` | startDate=yyyy-08-01, endDate=yyyy-08-31 |
| `来週月曜から水曜まで` | startDate=月曜日, endDate=水曜日 |
| `2025-08-10` | startDate=2025-08-10, endDate="" |

**アイデア抽出の対応フォーマット:**
- `プロジェクト名: 内容`（コロン区切り）
- `【タイトル】内容`（括弧形式）
- `■ タイトル`（記号形式: ■ ◆ ● ▼ ※）

### 確認シート（ConfirmSheet）

解析後にボトムシートで表示。内容確認後に保存。

- タップで各アイテムを編集
- ✕ ボタンで除外
- 各 TODO にコイン報酬バッジ（🪙 +N）を表示
- 確認後に一括確定保存

### タグ自動付与

**TODO タグキーワードマッピング:**

| タグ | 判定キーワード例 |
|------|----------------|
| 買い物 | 買う・購入・注文・スーパー など |
| 仕事 | 会議・資料・メール・報告・顧客 など |
| 家事 | 掃除・洗濯・料理・ゴミ など |
| 健康 | 病院・運動・薬・診察 など |
| 勉強 | 勉強・読書・資格・授業 など |
| その他 | 上記に一致しない場合 |

## 6. TODOシステム

### カレンダービュー

| 機能 | 内容 |
|------|------|
| 月表示 | 月単位カレンダー、各日のタスク件数バッジ表示 |
| 週表示 | 7 日間の週表示 |
| 切替 | 月/週ボタンでトグル |
| ナビゲーション | 左右スワイプ or ボタンで月/週移動 |

### タスク一覧セクション（上から順）

1. **ボスミッション**（その日発生している場合）
2. **期限切れ**（`endDate` < 今日）
3. **選択日のタスク**
4. **日付なしタスク**（折りたたみ可）

### フィルター

タグのチップを選択して絞り込み（複数選択可）。

### タスク完了時の挙動

1. チェックボックスをタップ
2. スパークル（8 方向パーティクル）アニメーション
3. 完了サウンド再生（設定に応じたサウンド種別）
4. `coinReward` コインを加算
5. チェックを外すと同額を減算

### コイン報酬（coinReward）の決定ロジック

**AI あり（Gemini / Claude）:**

| コイン範囲 | 目安 |
|-----------|------|
| 10〜30 | 買い物・連絡など数分でできるもの |
| 40〜80 | 家事・軽い仕事・30 分〜1 時間程度 |
| 90〜150 | 複雑な仕事・長時間作業・勉強など |
| 160〜200 | 大型プロジェクト・非常に困難なタスク |

**AI なし（ローカル推定 `estimateCoinReward`）:**

```
base = 30
+ タグ: 仕事/勉強 → +40、家事/健康 → +20
+ キーワード(高難度): 資料/企画/設計/開発/実装/レポート/プレゼン/調査/分析 → +60
+ キーワード(中難度): 作成/準備/計画/手続き/申請/修正/編集 → +30
- キーワード(低難度): 確認/チェック/送付/連絡/返信/予約 → -10
- キーワード(最低):   買う/購入/注文 → -15
+ タイトル長: >20 文字 → +20、>12 文字 → +10
→ 10〜200 にクランプ → 10 の倍数に丸め
```

## 7. アイデアシステム

### 表示

カード形式のグリッドレイアウト。各カードに以下を表示:
- プロジェクト名・概要・詳細（箇条書き）・タグ・更新日

### サブタブ

- デフォルト「すべて」タブは常に存在
- ユーザーが任意でタブを追加可能
- タブ自体もドラッグで並び替え可能
- アイデアカードをタブにドラッグ＆ドロップで移動

### ドラッグ＆ドロップ

| 入力 | 操作 |
|------|------|
| PC | マウスドラッグ |
| スマートフォン | 500 ms 長押し後ドラッグ（バイブレーション対応）|

### プロジェクトマージ

既存プロジェクトと同名（大文字小文字無視）のアイデアが来たとき:
- `details` 配列をマージ（重複排除）
- `tags` をマージ（重複排除）
- `updatedAt` を更新

| モード | コスト | 内容 |

## 10. メモモンシステム

### 登場モンスター

| ID | 名前 | レアリティ | 表示サイズ | 入手方法 |
|----|------|------------|-----------|---------|
| kuroneko | クロネコ | ★★★★★ ultra | 56×60px | 最初から所持 |
| skullon | ドクロン | ★★★★★ ultra | 66×60px | ガチャ |
| slime | スライム | ★★★★ super | 60×50px | ガチャ |
| hiyoko | ひよこ | ★★★★ super | 65×60px | ガチャ |
| obake | おばけ | ★★★★★ ultra | 65×60px | ガチャ |

### スプライットアニメーション

各モンスターに 6 アニメーション × 6 フレーム = 36 枚の PNG（全 5 体で 180 枚）。

| アニメーション | FPS | ループ | 発動条件 |
|--------------|-----|--------|---------|
| sit | 2 | ✓ | 通常待機 |
| walk | 8 | ✓ | 移動中 |
| happy | 6 | ✗ | タップ 1〜3 回目 |
| dislike | 6 | ✗ | タップ 4 回目以降（逃走前）|
| sleep | 2 | ✓ | 12 時間以上放置後の起動時 |
| surprise | 7 | ✗ | 睡眠中にタップされた時 |

### 行動ステートマシン

```
[idle] ←──────────────────────────────────────┐
  │ (30% 確率で walk へ)                         │
  ▼                                              │
[walk] → 端に当たる → 速度反転                  │
  │ (2〜4 秒後)                                  │
  ▼                                              │
[idle] (1〜3 秒 sit アニメ) ──────────────────┘

タップ 1〜3 回目:
  happy アニメーション再生（1 回）→ +10 コイン → sit

タップ 4 回目以降:
  [dislike-wait]（その場停止・dislike アニメーション再生）
    → [hiding]（最寄りの画面端へ移動・10 秒間）
    → [hidden]（10 分後に復活）

起動時（12 時間以上ぶり）:
  [sleep] → タップで [surprise] → [sit]
```

### 向き制御（spriteFacing）

```
flipH = (m.facing === 'l') XOR (def.spriteFacing === 'l')
el.style.transform = `scaleX(${flipH ? -1 : 1})`
```

- `spriteFacing` 省略 / `'r'`: スプライットが右向き（デフォルト）
- `spriteFacing: 'l'`: スプライットが左向き（スライムのみ）

### サイズ設定

| 設定値 | スケール倍率 |
|--------|------------|
| small | 0.75× |
| medium | 1.0×（デフォルト）|
| large | 1.5× |

### 動作範囲

- 上端マージン: 60px
- 下端マージン: 80px（ナビゲーションバー分）
- 端に到達すると速度を反転

## 11. サウンドシステム

Web Audio API でプログラム生成（音声ファイル不使用）。

| サウンド ID | 表示名 | 生成方式 |
|------------|--------|---------|
| doremi | ドレミ | sine 2 音（do-re）|
| pop | ポップ | sine 880→440Hz ランプダウン |
| chime | チャイム | sine 3 音シーケンス（C・E・G）|
| coin | コイン音 | square B5→E6 クイック |
| mario | マリオ音 | square クラシックコイン音 |
| 8bit | 8 ビット | square 4 音アルペジオ |
| bell | ベル | sine 3 倍音 1 秒サスティン |
| fanfare | ファンファーレ | triangle 4 音上昇 |
| special | 特製メロディ | triangle 5 音上昇メロディ |

- AudioContext はサウンド初回再生時に遅延初期化
- suspended 状態の場合は `resume()` を自動呼び出し

## 14. PWA・データ永続化

### Service Worker（`sw.js`）

| 項目 | 内容 |
|------|------|
| キャッシュ名 | `smartmemo-v34` |
| キャッシュ戦略 | Stale-while-revalidate |

**キャッシュ対象:**
- `index.html`, `app.tsx`, `manifest.webmanifest`, `icon.svg`
- Google Fonts（Inter）
- React 18.3.1 / ReactDOM / Babel standalone（CDN）
- スプライット PNG: `kn_*`・`sl_*`・`sk_*`・`hy_*`・`ob_*`（各 36 枚、計 180 枚）

### データ永続化

- `navigator.storage.persist()` を起動時に呼び出し（対応ブラウザのみ）
- ページ非表示・visibility 変更時に即時フラッシュ
- すべてのデータは `localStorage` に JSON で保存
