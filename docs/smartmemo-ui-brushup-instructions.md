# SmartMemo UI ブラッシュアップ 指示書（Claude Code 向け）

対象: SmartMemo v1.40.0（PWA、実機基準 390×844）
目的: 機能は一切変えずに、画面ごとにバラついている見た目と操作の「型」を 1 つに揃える。
参照モック: Claude Design キャンバス「SmartMemo UI ブラッシュアップ案」（にわ／メモ／設定トップの現状と提案の並び）

---

## 0. 作業の進め方（必ず守る）

1. **最初にコードベースを調査して報告してから着手する。** 以下を把握し、ファイルパス付きで短くまとめてから次に進むこと。
   - デザイントークンの定義場所（CSS 変数、Tailwind config、テーマオブジェクトなど）。ベースカラー 5 色（オレンジ／青／緑／ピンク／ネイビー）、ダークモード、ガラス風デザイン、文字サイズ 小中大 がどう実装されているか
   - 共通コンポーネント（ボタン、チップ、カード、ボトムシート、モーダル、ヘッダー、ボトムナビ）の有無と場所
   - 各タブ画面と 16 モーダルのコンポーネント一覧
2. **機能・データ・設定項目は追加も削除もしない。** この指示書は見た目と配置の変更のみ。設定の「反映ボタンの分割」のように、既存のオプションが UI の意味を変える箇所は、そのオプションを尊重したまま新デザインに合わせる。
3. **段階ごとにコミットし、各段階の終わりに 390×844 でスクリーンショットを撮って確認する。** ライト／ダーク両方、ガラス風 ON/OFF、ベースカラーはオレンジと青の 2 色を最低限確認する。
4. 迷った点・仕様と矛盾した点は、勝手に決めずにその段階の報告に「未決事項」として列挙する。

## 1. 設計原則（判断に迷ったらここに戻る）

- **土台は 1 色 + グレー。** 主ボタン、選択状態、アクティブなナビ、バッジはすべて「ベースカラー」1 色。画面固有の色（メモの緑・黄、書庫の紫、書庫のベージュ背景、ガチャのグラデーションボタン、集中モードの水色/パステル緑）は廃止する。
- **遊びはメモモン領域に限定する。** 庭の絵、ドット絵のメモモン、ガチャの演出、ずかんのシルエットは変えない。ただしそれらを包む UI（ボタン、カード、余白、フォント）は共通トークンを使う。
- **モーダルは 2 種類だけ。** 編集・選択・確認 → ボトムシート。没入するもの（集中モード、メモモン画面、ガチャ、書庫にきく）→ フルスクリーンで、共通の戻るヘッダーを持つ。中央ダイアログは使わない。
- **1 行 1 目的。** タスク行や設定行に並ぶ要素は「主情報 + 補助 1〜2 個」まで。常時表示の破壊操作（×）は置かない。
- **愛称は本文、機能名はナビ。** 画面タイトルは「にわ」「書庫」「ずかん」のまま。ボトムナビのラベルは「タスク」「ナレッジ」「メモ」「メモモン」「設定」の 1 行にする。

## 2. デザイントークン

既存のトークン定義に **追加または置き換え** で導入する。値はモックから起こした暫定値なので、既存の定義と大きくズレる場合は既存に寄せてよい（その場合は報告に書く）。

```
/* ベース（ライト） */
--bg:          #F7F6F3;   /* 画面背景。わずかに暖色 */
--surface:     #FFFFFF;   /* カード、シート、ナビ */
--sunk:        #F1EFEA;   /* タグ背景、アイコン座布団、区切り線の薄い方 */
--rule:        #E6E4DF;   /* カード枠、ナビ上罫線 */
--ink:         #1B1B1F;
--ink-2:       #55555E;   /* 補助テキスト */
--ink-3:       #8A8A92;   /* ラベル、非アクティブなナビ */
--ink-4:       #B4B3AE;   /* プレースホルダ、シェブロン */
--accent:      <ベースカラー設定の値>  /* 既定 #E4732F */
--accent-ink:  #FFFFFF;
--coin:        #F2C230;   /* コインだけは固定色 */

/* 角丸 */
--r-card: 14px;  --r-sheet: 20px;  --r-pill: 999px;  --r-tag: 6px;

/* サイズ */
--h-header: 52px;  --h-nav: 76px;  --h-row: 56px;  --h-btn: 44px;  --h-btn-lg: 52px;  --h-chip: 30px;
--fab: 52px;  --space: 16px（画面左右）;  --gap: 8px;

/* 文字（「中」基準。小/大は既存の倍率をそのまま） */
--fs-title: 17px/700;  --fs-page: 22px/700;  --fs-body: 14px/500;  --fs-sub: 12px;  --fs-label: 11px;
```

ダークモードは既存のダーク値を上記の役割名にマッピングし直す。新しい色を発明しない。
ガラス風デザインは `--surface` と `--bg` に半透明 + backdrop-filter を当てるだけの差分にし、それ以外のトークンは共通にする。

ベースカラー 5 色は `--accent` を切り替えるだけで全画面が追従すること。**アクセント色をハードコードしている箇所（緑 #40b060 系、黄 #e8a820 系、紫、ガチャのグラデーション）を grep で洗い出して全部 `--accent` に置き換える。**

## 3. 共通コンポーネント（先に作る／揃える）

### 3.1 ヘッダー
- 高さ 52px。左: アプリアイコン（20px）+ ワードマーク「SmartMemo」（15px/700）。右: コインチップ。
- **日付表示は削除する**（にわの日付欄に一本化）。
- コインチップ: 白背景・`--rule` 枠・pill。中に コインアイコン + 数値（3 桁区切り、tabular-nums）+ 「ガチャ」ボタン（`--accent` 塗り、24px 高、pill）。タップ領域はチップ全体で 44px 以上確保。

### 3.2 ボトムナビ
- 高さ 76px、`--surface`、上罫線 `--rule`。5 等分グリッド。
- 各項目: 24px ストロークアイコン + 11px ラベル 1 行。アクティブは `--ink` + 700、非アクティブは `--ink-3`。**2 段ラベルを廃止**。
- ラベル: タスク／ナレッジ／メモ／メモモン／設定。
- 中央の FAB: 52px 円、`--accent`、上に 30px はみ出す。影は `--accent` の 30% 透過で 0 6px 16px。ラベル「メモ」は他と同じ 11px。

### 3.3 ボタン
- primary: `--accent` 塗り、白文字 14px/700、高さ 44px（画面の主 CTA は 52px/15px）、pill。
- secondary（ghost）: 白、`--rule` 枠、`--ink` 文字、同じ高さ・pill。
- アイコンのみ: 40×40 の ghost。
- disabled: primary の不透明度 40%。**別色（薄いオレンジ・薄い緑）を使わない。**

### 3.4 チップ（フィルタ／選択肢）
- 高さ 30px、pill、12px。未選択: 白 + `--rule` 枠 + `--ink-2`。選択: `--accent` 塗り + 白 + 700。
- タスク編集の「繰り返し」「タグ」の選択肢もこれで統一。

### 3.5 タグ（表示用）
- 11px、`--sunk` 背景、`--ink-2`、角丸 6px、padding 1px 8px。色分けしない。

### 3.6 カード
- `--surface`、`--rule` 1px 枠、角丸 14px。影は付けない（ガラス風 ON のときだけ既存の影を許可）。

### 3.7 ボトムシート
- 角丸 20px 20px 0 0、上に 36×4 のハンドル、左右 16px。タイトル 17px/700。
- フッターのボタン列は「キャンセル（ghost）」「保存（primary）」の 2 分割、高さ 44px。
- 既存のタスク編集／追加、TODO セット、ゴミ箱、メモ履歴、AI 反映の確認、餌をえらぶ、アカウント、AI 分析 をすべてこの 1 実装に載せる。

### 3.8 フルスクリーン画面の共通ヘッダー
- 高さ 52px。左: 戻る（シェブロン + 遷移元のタブ名、例「‹ にわ」）。中央: 画面名 17px/700。右: 必要なら閉じる／コイン。
- 集中モード、メモモン画面、ガチャ、書庫にきく、メモモンの詳細 をこれに載せる。

### 3.9 アイコン
- 絵文字は使わない。ストローク 1.6〜1.8px の SVG アイコンセット 1 種類に揃える（既存でアイコンライブラリを使っているならそれに統一）。

## 4. 画面別の変更

### 4.1 にわ（タスク）
- 庭: 高さ 236px。「集中モード」は左上の白 pill（36px 高、アイコン + 文字）、時間帯アイコンは右上の 36px 白丸。
- 看板の文言: **全角 6 文字で切り詰め、末尾は省略記号なし**（看板が小さいので）。正式名はシートのタスク行で見せる。
- シート: 角丸 20px、ハンドル、`--surface`。
  - 1 行目: 「きょうのタスク」17px/700 + 「0 / 2」`--accent` 13px/700。右端に 日付「8/14（金）」13px + カレンダーアイコン（既存のカレンダー展開のトリガー）。
  - 2 行目: フィルタチップ。**先頭に「すべて」を追加し、未選択時はこれが選択状態**。既存のタグ列の挙動（フィルタ）は変えない。横スクロール。
  - タスク行（56px）: チェック丸 24px → タイトル（1 行、省略）→ タグ → 時刻。
    - 時刻の表示規則: 今日のタスクは `10:00`、時刻なしは `終日`（`--ink-3`）、別日は `8/15 10:00`。ISO 形式 `2026-08-14 10:00` は表示しない。
    - **行内の「複製」「×」アイコンを削除。** 削除は行の左スワイプ、複製は長押しメニュー（または編集シート内）に移す。実装コストが高い場合はまず編集シート内に「複製」「削除」を置き、スワイプは次段階でよい。
  - 「日付未定 · 1」は 36px の折りたたみ見出し（12px/700 `--ink-3` + シェブロン）。
  - 最下段: 「＋ タスクを追加」primary（flex:1）＋「セット」ghost ＋ ゴミ箱アイコン ghost（40px）の 1 行。既存の 3 つのテキストリンクを置き換える。
- タスク一覧を全画面（niwa-sheet）、カレンダー展開（niwa-calendar）は同じシート内の状態として、上記のスタイルを引き継ぐ。

### 4.2 メモ
- テキストエリアをカード（角丸 14px、padding 16px）にし、上部に「思いついたことを書く」ラベルと文字数、下部に 1 行の説明「予定・買い物・アイデアが混ざっていても、AI が TODO とナレッジに分けます。」（12px `--ink-3`、上罫線 `--sunk`）。
- ツール列: 音声／画像／添付／リンク／履歴 を **同じ形の 5 等分ボタン**（56px 高、アイコン + 11px ラベル、ghost）に統一。**履歴を右端に浮かせない。**
- 主ボタン: 「AI に反映」1 つ、52px、primary、幅いっぱい。
  - 設定「反映ボタンの分割」が ON のときだけ「TODO に反映」「ナレッジに反映」の 2 分割にするが、**両方とも primary（`--accent`）と ghost の組み合わせ**にし、緑・黄は使わない。
- 以降の「AI 反映の確認」シートは 3.7 の共通シートへ。抽出結果の行はタスク行と同じ 56px の型（タイトル／日付／タグ／コイン加算はタグ扱い）。

### 4.3 設定
- トップを **一覧ページ** に変える。ページタイトル「設定」22px/700。
  - 先頭: アカウントカード（アイコン 44px 丸／「未ログイン」／「ログインすると複数端末で同期」／右に primary「ログイン」）。Supabase 未設定時は非表示（現行仕様どおり）。
  - グループ「アプリ」: 表示 ／ カレンダー・通知 ／ AI ／ タグ
  - グループ「メモモン」: メモモン ／ プレゼントコード
  - グループ「データ・その他」: データ管理 ／ アプリ情報
  - 各行 58px: 36px の `--sunk` 座布団アイコン + タイトル 14px/700 + サブテキスト 11px（そのサブページに何があるかの要約）+ 右シェブロン。
- サブページは 3.8 の共通ヘッダー付き。既存の 13 セクションを以下に再配置する（**設定項目そのものは増減させない**）:
  - 表示 ← 表示
  - カレンダー・通知 ← カレンダー・休日 + 通知・サウンド
  - AI ← AI 連携 + AI 分析 + AI 設定（この順で縦に並べる。分析ボタンの活性条件は現行どおり）
  - タグ ← タグ
  - メモモン ← メモモン
  - プレゼントコード ← プレゼントコード
  - データ管理 ← データ管理
  - アプリ情報 ← アプリ情報 + テスト（コイン無限モードは解放済みのときだけ、アプリ情報の末尾に出す）
- トグル、セグメント（小/中/大）、カラースウォッチは既存を流用し、色は `--accent` に揃える。

### 4.4 書庫（ナレッジ）
- ベージュ背景を廃止し `--bg`。本棚（背表紙）の描画は変えない。
- 「書庫にきく」ボタンは紫をやめ primary。
- 検索欄はカード型（白、`--rule` 枠、pill）。
- 空状態: 「まだ本がありません」の下に「メモを書く」primary ボタンを置き、タップでメモタブへ。

### 4.5 ずかん（メモモン）
- グリッドのカードを 3.6 のカードに。シルエット／???／レアリティ星／レアリティ名（ウルトラ等）は変えない。レアリティ名は 3.5 のタグ型（色分けなし）。
- 「メモモンの詳細」（未所持）は中央ダイアログをやめ、ボトムシートに。
- 「メモモン画面」はフルスクリーン（3.8）。「なでる」「餌をあげる」は primary／ghost、「にわにお出かけ」は primary 幅いっぱい。緑は使わない。
- 「餌をえらぶ」はボトムシート。餌カードの色分け（黄・緑・青・赤）は廃止し、白カードにレアリティ星と価格のみ。

### 4.6 ガチャ
- 紺の背景は「演出面」として維持してよいが、**ボタンはグラデーションをやめ primary**。単発／10連／メモモン確定 はチップ（3.4）。
- 結果画面も同じ。「もう一度引く」primary、閉じるは ghost。

### 4.7 集中モード
- 水色背景を `--bg` に。タイマーの数字は 48px/700 tabular-nums。
- 「再開」「完了」はそれぞれ ghost／primary（パステルはやめる）。
- 割り込みの入力欄 + 「開始」は入力欄（44px）と primary ボタンの 1 行。候補チップは 3.4。
- 「きょうのタスク」の各行は 4.1 のタスク行の型に、先頭の再生アイコンだけ差し替え。

### 4.8 その他のモーダル
- タスクを編集／追加: 3.7 のシート。フィールドラベル 12px `--ink-3`、入力 44px。「終了日」は既定で折りたたみ、「期間にする」リンクで展開（データは変えない）。削除は右上のゴミ箱アイコンのまま（ここは編集画面なので常時表示でよい）。
- ゴミ箱、TODO セット一覧／作成、メモ履歴、アカウント、AI 分析: 3.7 のシート。ボタンは 3.3。

## 5. 実施順序（1 段階 = 1 コミット以上）

1. トークン導入と、アクセント色ハードコードの一掃（見た目はまだ変わらなくてよい）
2. 共通コンポーネント: ヘッダー／ボトムナビ／ボタン／チップ／タグ／カード
3. にわ（タスク行、フィルタ、下段ボタン、看板文言）
4. メモ（ツール列、主ボタン、確認シート）
5. ボトムシート共通化と、各モーダルの載せ替え
6. 設定のページ分割
7. 書庫・ずかん・餌・メモモン画面
8. ガチャ・集中モードのフルスクリーン共通ヘッダー化
9. ダーク／ガラス風／文字サイズ 3 段階／ベースカラー 5 色 の総当たり確認とスクリーンショット

各段階の終わりに、変更ファイル一覧・スクリーンショット・未決事項を報告する。

## 6. 受け入れ基準

- `grep` でアクセント系の色コードがトークン定義以外に残っていない。
- 5 タブと 16 モーダルのすべてで、主ボタンが `--accent`、二次ボタンが ghost。
- 中央ダイアログが 0 個。フルスクリーン画面はすべて同じヘッダー。
- ボトムナビのラベルが 1 行 5 語。ヘッダーに日付が出ない。
- にわのタスク行に常時表示の削除／複製アイコンがない。時刻が ISO 形式で出ない。
- 設定トップが 8 項目のリストで、13 セクションの項目が漏れなくサブページに存在する。
- ライト／ダーク、ガラス風 ON/OFF、文字サイズ 小/中/大、ベースカラー 5 色 の組み合わせで崩れがない（最低限 ライト×オレンジ、ダーク×青、ガラス ON×ピンク の 3 組は必ず確認）。
- 機能・保存データ・設定項目に変更がない（差分が UI 層に限られている）。

## 7. やらないこと

- 新機能、設定項目の追加・削除、データ構造の変更
- メモモンのドット絵、庭の絵、ガチャ演出のアート差し替え
- タブ名（にわ／書庫／ずかん）の改名
- アニメーションの新規追加（既存のものは維持）
