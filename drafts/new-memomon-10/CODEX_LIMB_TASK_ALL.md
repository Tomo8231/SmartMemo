# Codex への依頼: メモモン全員分の、手足が動くポーズを画像生成で描く

## 目的

試作の 3 体（しろにゃん・マフラーペン・ちびナイト）と同じ方法で、指定されたメモモンの
**手足が動くポーズ** を画像生成で描いてください。描いた画像はこちらで切り出してアニメーションのコマにします。
試作の出来上がりは `limb_frames/shironeko1_*.png` `limb_frames/penguin2_*.png` `limb_frames/knight1_*.png` にあります。
**この 3 体と同じ形式・同じ仕上がり** を目指してください。

担当するメモモンの id は、依頼のメッセージで指定します（例: `panda2`）。

- id の数字を除いた部分が系統（`panda`）、数字が段階（`2`）
- 参照画像: `generator/base_cut/<系統>_<段階>.png`（背景を透明にした切り抜き。例: `generator/base_cut/panda_2.png`）
- 元のシート: `base_image/`（黒背景・白フチ）

## 作る画像（1 体につき 2 枚）

保存先: `limb_frames/<id>_walk.png` と `limb_frames/<id>_actions.png`
**すでに両方のファイルがある id は作り直さない**（途中で止まったときに続きから再開するため）

### 1. `<id>_walk.png` — 歩き 6 コマ（3 列 × 2 行）

- 読む順は 左上 → 右上 → 左下 → 右下
- その場で左へ歩く一周分。足を交互に前へ出し、腕（前足・ヒレ・翼）も足と逆に振る
- 表情はふつう（参照画像のまま）

### 2. `<id>_actions.png` — 4 つのポーズ（2 列 × 2 行）

左上から次の順
1. **喜ぶ**: 両手を高く上げてジャンプ。にっこり目で口を大きく開ける
2. **嫌がる**: ぷいっと顔をそむけ、じたばたする。「><」の目、への字の口
3. **寝る**: 丸くなって（または座ったまま）眠る。閉じた目
4. **驚く**: 両手を広げて飛び上がる。丸く見開いた目、「o」の口

### 手足のないキャラクター

星・雲・音符・宝箱・かぼちゃ・火の玉・サボテン・クジラ・ふたば など、手足がない（または短い）キャラは、
次のように **形のある部分を手足の代わりに動かして** ください。新しく手足を生やさないこと。

- 歩き: 体を左右に傾けながら、ぴょこぴょこ跳ねて進む。星のとがり・雲のふくらみ・クジラの尾びれ・音符の旗・サボテンの腕・宝箱のふた・炎の先・葉っぱ などを交互にゆらす
- 喜ぶ・驚く: 体を大きく伸ばし、とがり・ふくらみ・ひれ・ふたなどを大きく広げる
- 嫌がる: 体をぷいっとひねり、ぎゅっと縮める
- 寝る: 体を低く平たくして、ぐったりさせる
- 顔がないキャラ（宝箱）は、ふたの開き具合と、中からのぞく目・口で表情を出してよい。顔がヘルメットで見えないキャラ（ナイト）は、のぞき穴の中の目の形で表情を出す

## 絵の決まり（切り出しを自動でするので必ず守る）

- 背景は**真っ黒（#000000）一色**。グラデーション・床・影・模様を描かない
- キャラの外側に**白い細いフチ**（元のシートと同じ）
- 1 マスに 1 キャラだけ。マス同士は十分に離し、はみ出したり重なったりしない。エフェクト（火花・きらきら等）もマスの外にはみ出さない
- すべてのコマで**同じ大きさ・同じ画風・同じ色・同じ装飾**（参照画像にそろえる。服や小物を増やしたり減らしたりしない）
- **参照画像と同じ向き（体と顔の向き）を保つ**。参照画像が斜め左向きなら全コマ斜め左向き。横顔にしない
- ドット絵風の画風を参照画像に合わせる
- 文字・番号・枠線を描かない

## 進め方

1. 担当 id ごとに、参照画像を見てキャラの特徴（色・模様・小物・向き）を確認する
2. 画像生成で 2 枚作る。参照画像を入力に使う
3. 出来た画像を見て、上の決まり（黒背景・マス目の数・向き・見た目の一致）を満たさなければ作り直す
4. `limb_frames/` に保存する

## 触らないもの

- このフォルダ（`drafts/new-memomon-10/`）の外は変更しない
- `generator/`・`base_image/`・`limb_preview/` と、担当以外の `limb_frames/` のファイルは変更しない
- git の操作（add / commit / branch / push）はしない
- 最後に、作った画像の一覧と、うまくいかなかった id を日本語で短く報告する
