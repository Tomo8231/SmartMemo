# Codex への依頼: メモモンの手足が動くポーズを画像生成で描く（試作 3 体）

## 目的

メモモンは今、1 枚の静止画を傾けたり伸ばしたりして動かしており、手足が動きません。
画像生成を使って、同じキャラクターの **手足が動くポーズ** を描いてください。
描いた画像はこちらで切り出して、アニメーションのコマにします。

まずは次の 3 体だけです（出来を見てから全 102 体に広げます）。

| id | 名前 | 参照画像 | 形 |
|---|---|---|---|
| shironeko1 | しろにゃん | `generator/base_cut/shironeko_1.png` | 四つ足のねこ |
| penguin2 | マフラーペン | `generator/base_cut/penguin_2.png` | ヒレのある二本足のペンギン |
| knight1 | ちびナイト | `generator/base_cut/knight_1.png` | 剣を持つ小さな騎士（人型） |

参照画像は背景を透明にした切り抜きです。元のシートは `base_image/` にあります（黒背景・白フチ）。

## 作る画像（1 体につき 2 枚）

保存先: `limb_frames/<id>_walk.png` と `limb_frames/<id>_actions.png`

### 1. `<id>_walk.png` — 歩き 6 コマ

- **3 列 × 2 行**のマス目に 1 コマずつ。読む順は左上 → 右上 → 左下 → 右下
- 左へ歩く一周分の 6 コマ。足を交互に前へ出し、腕（前足・ヒレ）も足と逆に振る
  1. 右足を前に着地 2. 体が一番高い（片足を上げて通過） 3. 反対の足が前へ出始める
  4. 左足を前に着地 5. 体が一番高い（反対側） 6. 最初のコマへ戻る途中
- 表情はふつう（元の絵のまま）

### 2. `<id>_actions.png` — 4 つのポーズ

- **2 列 × 2 行**のマス目。左上から次の順
  1. **喜ぶ**: 両手（前足・ヒレ）を高く上げてジャンプ。にっこり目で口を大きく開ける
  2. **嫌がる**: ぷいっと顔をそむけ、片足で地団駄。「><」の目、への字の口
  3. **寝る**: 丸くなって（または座ったまま）眠る。閉じた目
  4. **驚く**: 両手を広げて飛び上がる。丸く見開いた目、「o」の口

## 絵の決まり（切り出しを自動でするので必ず守る）

- 背景は**真っ黒（#000000）一色**。グラデーション・床・影・模様を描かない
- キャラの外側に**白い細いフチ**（元のシートと同じ）
- 1 マスに 1 キャラだけ。マス同士は十分に離し、はみ出したり重なったりしない
- すべてのコマで**同じ大きさ・同じ画風・同じ色・同じ装飾**（元の絵にそろえる。服や小物を増やさない）
- キャラは**左向き**（歩きは左へ進む）
- ドット絵風の画風を元の絵に合わせる
- 文字・番号・枠線を描かない

## 進め方

1. 参照画像を見て、キャラの特徴（色・模様・小物）を確認する
2. 画像生成で 2 枚ずつ作る。参照画像を入力に使える場合は必ず使う
3. 出来た画像を見て、上の決まり（黒背景・マス目・左向き・見た目の一致）を満たさなければ作り直す
4. `limb_frames/` に保存する

## 触らないもの

- このフォルダ（`drafts/new-memomon-10/`）の外は変更しない
- `generator/` の中のファイルと `base_image/` は変更しない
- git の操作（add / commit / branch / push）はしない
- 最後に、作った画像の一覧と、うまくいかなかった点を日本語で短く報告する
